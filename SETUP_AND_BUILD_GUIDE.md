# Повний посібник: Збірка та використання Telegram X (Nicegram Edition)

У цьому посібнику покроково описано, як зібрати власний надшвидкий клієнт **Telegram X** із дизайном та фічами **Nicegram / iOS**, використовуючи безкоштовну хмарну збірку через **GitHub Actions**.

---

## Чому саме цей білд «вивозить» 500+ каналів?
1. **Чистий рушій TDLib (C++)**: Не створює монолітних блокувань пам'яті, як офіційний клієнт Telegram чи AyuGram.
2. **Асинхронний кеш SQLite**: Навіть якщо одночасно приходять тисячі постів у 500 каналів, інтерфейс не смикається і тримає стабільні 60–120 FPS.
3. **Оптимізована черга відправки**: Навіть під час розсилки по 100 групах телефон не зависає.

---

## Крок 1: Створення власного форку на GitHub

1. Відкрийте офіційний репозиторій: **[https://github.com/TGX-Android/Telegram-X](https://github.com/TGX-Android/Telegram-X)**.
2. У правому верхньому кутку натисніть кнопку **«Fork»**.
3. Назвіть репозиторій (наприклад, `Telegram-X-Nicegram`) і натисніть **«Create fork»**.

---

## Крок 2: Додавання наших файлів у ваш форк

> ⚠️ **Важливо:** Файли потрібно додати у правильні директорії вашого форку!

У вашому форку додайте файли, підготовлені у папці `tgx-nicegram`:

| # | Файл | Куди копіювати | Призначення |
|:--|:-----|:---------------|:------------|
| 1 | `build.yml` | `.github/workflows/build.yml` | Сценарій автоматичної збірки APK у хмарі |
| 2 | `Nicegram Dark.tgx-theme` | `app/src/main/other/themes/` | Темна тема із заокругленнями 18dp та палітрою Nicegram |
| 3 | `Nicegram Light.tgx-theme` | `app/src/main/other/themes/` | Світла тема у стилі iOS з фіолетовим акцентом |
| 4 | `BottomNavigationLayout.java` | `app/src/main/java/org/thunderdog/challegram/navigation/` | Нижня панель навігації у стилі iOS |
| 5 | `HiddenChatsManager.java` | `app/src/main/java/org/thunderdog/challegram/tool/` | Приховування чатів із захистом PIN-кодом (SHA-256 + salt) |
| 6 | `FolderBatchSender.java` | `app/src/main/java/org/thunderdog/challegram/tool/` | Масова розсилка по 100+ групах із захистом від FloodWait |

### Як завантажити файли через GitHub Web:
1. Відкрийте ваш форк на GitHub.
2. Перейдіть у потрібну директорію (наприклад, `.github/workflows/`).
3. Натисніть **«Add file»** → **«Upload files»** або **«Create new file»**.
4. Вставте вміст файлу та натисніть **«Commit changes»**.

### Або через Git CLI:

## Крок 3: Налаштування ключів Telegram API

Telegram вимагає, щоб кожен клієнт мав унікальну пару `api_id` та `api_hash`:

1. Перейдіть на офіційний сайт: **[https://my.telegram.org](https://my.telegram.org)**.
2. Увійдіть за своїм номером телефону Telegram.
3. Перейдіть у розділ **«API development tools»**.
4. Заповніть коротку форму:
   * **App title:** `TGX Nicegram`
   * **Short name:** `tgxnicegram`
   * **Platform:** `Android`
5. Скопіюйте отримані **`api_id`** (число) та **`api_hash`** (рядок з літер і цифр).
6. У вашому GitHub репозиторії перейдіть:
   * **Settings** → **Secrets and variables** → **Actions** → **New repository secret**.
   * Створіть секрет: `TGX_API_ID` (значення вашого api_id).
   * Створіть секрет: `TGX_API_HASH` (значення вашого api_hash).

> 💡 Якщо не налаштувати секрети, білд автоматично використає тестові ключі за замовчуванням.

---

## Крок 4: Запуск автоматичної збірки (GitHub Actions)

1. Перейдіть у вкладку **«Actions»** у вашому репозиторії на GitHub.
2. Зліва оберіть workflow **«Build Telegram X (Nicegram Edition)»**.
3. Натисніть праворуч кнопку **«Run workflow»** (оберіть гілку `main` та тип `debug`).
4. Зачекайте **~15-30 хвилин**: хмарний сервер Ubuntu завантажить NDK `23.2.8568313`, скомпілює TDLib та додаток.
5. Після завершення клікніть на виконаний запуск, прокрутіть униз до розділу **Artifacts** і завантажте **`TelegramX-Nicegram-APK`**.
6. Перекиньте файл `.apk` на телефон та встановіть!

> ⚠️ Перший білд може зайняти до **30-45 хвилин** через компіляцію TDLib. Наступні білди з кешем будуть набагато швидшими (~15 хв).

## Огляд нових фіч у додатку

### 1. 🔽 Нижня панель (iOS Bottom Bar)
* Замість незручного витягування бічної шторки (Drawer) у додатку тепер доступна нижня панель із 4 вкладками: **Чати**, **Дзвінки**, **Контакти**, **Налаштування**.
* Червоні бейджі з лічильниками непрочитаних повідомлень.
* Плавні анімації перемикання вкладок з тактильним відгуком.
* Векторні іконки, які адаптуються під будь-яку тему.

### 2. 🎨 Теми Nicegram (Dark + Light)
* У **Налаштуваннях → Теми** оберіть **Nicegram Dark** або **Nicegram Light**:
  * Плавні заокруглені бульбашки повідомлень (18dp зовнішній радіус, 6dp згруповані).
  * **Dark:** OLED глибокий чорний фон (`#000000`), фіолетовий акцент (`#6C5CE7`).
  * **Light:** Чистий білий фон, світло-сірі вхідні бульбашки, фіолетовий акцент.

### 3. 🔒 Приховані чати (Hidden Chats)
* Будь-який чат чи канал можна приховати зі списку (довгий тап по чату → **«Приховати чат»**).
* Приховані чати зникають із загального списку, глобального пошуку та лічильників.
* Захист **4-значним PIN-кодом** з хешуванням SHA-256 + випадкова сіль.
* Дані зберігаються в зашифрованому сховищі (EncryptedSharedPreferences).

### 4. 📨 Мульти-виділення папки та розсилка з затримкою
* У списку чатів перейдіть у потрібну папку (наприклад, з вашими 100 групами).
* Натисніть меню → **«Виділити всі в папці»** (всі 100 груп виділяються миттєво).
* Оберіть **«Відправити / Переслати»** → диспетчер черги автоматично надсилає повідомлення:
  * Затримка **2 секунди** між групами (налаштовується).
  * Автоматична обробка `FloodWait` з повторними спробами (до 3 разів).
  * Прогрес-бар відправки без блокування інтерфейсу.
  * Колбек помилок для кожного чату.
